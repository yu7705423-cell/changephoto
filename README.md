# 图床搬家工具

贴一段 HTML / CSS 代码进去，它会把里面所有图片链接挖出来、缩略图排开，
让你一键打包下载，或者一键转存到新图床，最后再给你一份换好链接的代码和新旧对照表。

还没有图床的话，它也能一步步带你搭一个。

**纯前端，打开网页就能用。** 图片和图床 token 都只在你自己的浏览器里，
不经过任何第三方服务器（配了中转的话，只经过你自己部署的 Cloudflare Worker）。

界面是纯黑白的，跟随系统深色模式，也可以在右上角手动切日间 / 夜间。
状态全靠符号和描边区分（✓ 能加载、✕ 已失效、实心＝可信度高、虚线＝低），不靠颜色，
所以色盲和黑白打印都读得出来。

## 能做什么

| | |
|---|---|
| **直接传图** | 不贴代码也行：选文件、选整个文件夹、拖进来、或者截图后直接 Ctrl+V，批量传到图床拿链接 |
| **批量代码文件** | 一次选一堆 css / html，各自独立提取、独立导出，不会被合并成一坨。同一张图在多个文件里出现，会在每个文件里都替换掉 |
| **提取** | `img` 的 src / srcset / data-src 等懒加载属性、CSS 的 `url()`、行内 style、SVG `<image>`、`og:image`、Markdown 图片、正文里的裸链接、`data:` 内嵌图，自动去重合并 |
| **展示** | 缩略图网格，每张标出「能加载 + 尺寸」还是「已失效」 |
| **保存到本地** | 四种方式：系统分享（手机）、存到文件夹（电脑）、逐张保存、打包 ZIP。文件一律按 `001-xxx.png` 顺序编号，附带 `清单.csv` |
| **转存** | GitHub + jsDelivr、ImgBB、S.EE（原 SM.MS）、Cloudflare R2，以及任意自定义接口（兰空 / Chevereto 等）。有进度条，失败的单独列出来可以重试 |
| **对照** | 前后两栏并排显示，中间写清「依据」和「可信度」，可以点选交换、上下移动、单独粘链接覆盖 |
| **导出** | 自动把原代码里的旧链接换成新链接，另附新旧对照表（CSV / Markdown / JSON），以及新链接列表（纯链接 / Markdown / HTML / BBCode） |
| **搭建图床** | 还没有图床的话，从注册账号到拿 token 一步步带着做，每步都有直达链接。测试连接通过后配置自动填进转存页 |
| **进度不会丢** | 提取结果、配好的对照、抓回来的图片都存在本机。手机切走再回来、或者误关页面，重新打开接着上次继续，图也不用再抓一遍 |

失效的图（比如对象存储已经 `NoSuchKey` 的）会明确标成「已失效」，不会假装成功。

## 一次处理一堆 css / html

点「选择代码文件」可以一次选多个，也可以直接把文件拖到页面上。每个文件是独立的：

- 上面会出现一排文件标签，点哪个就编辑哪个，不会被合并成一大坨
- 提取时跨所有文件扫一遍，同一张图只算一条，但**每个文件里的每一处都会被替换**
- 导出时同样按文件分开，每个标签上标着这个文件改了几处，
  可以单个复制 / 下载，也可以「打包下载全部文件」（附带链接对照表）
- 文件名会保留，导出成 `header-已替换.css` 这样

## 支持哪些图片格式

PNG、JPG、**SVG**、GIF、WebP、AVIF、BMP、ICO、TIFF、HEIC，以及 `data:` 内嵌图，
提取、缩略图、打包下载、图像指纹比对都一视同仁。

SVG 需要注意的不是这个工具，而是**图床那一端**：ImgBB 和 S.EE 一般只收位图，
传 SVG 会被拒（工具会在报错里直接告诉你原因和替代方案）。
要传 SVG 就用 **GitHub + jsDelivr** 或 **Cloudflare R2**，它们什么格式都收。

## 只想传图拿链接？

不用贴代码。「输入」页有个**直接传图片**：

- 选文件、选整个文件夹，或者把图拖到页面上，或者截完图直接 Ctrl / ⌘ + V 粘贴
  （拖进来的如果是 css / html，会自动当代码文件处理，不会搞混）
- 文件会**按文件名排序**编号（001、002…），传上去的名字和顺序跟你在文件管理器里看到的一致
- 传完在「导出」页直接拿到**新链接列表**，四种格式随便切：纯链接、Markdown、HTML、BBCode
- 这些图同样存在本机缓存里，刷新页面不会丢

## 进度不会丢

手机浏览器会把后台标签页直接回收掉，切个微信回来页面就等于重新打开了。
所以工具会随时把进度存在这台设备上：

- **存什么**：贴进去的代码、提取出来的图片列表和检测状态、配好的新旧对照、
  甚至已经抓回来的图片二进制，都存在浏览器的 IndexedDB 里
- **怎么恢复**：重新打开自动接上，顶部会有一条「接着上次继续：12 张图、已配好 8 对」，
  还会停在你上次看的那一页。不想要就点旁边的「清掉，重新开始」
- **图不用重抓**：抓过一次的图存着，再打包、再上传、换个标签页打开都直接用缓存，
  不会再去烦源站，配了中转的话也省流量
- **只在本机**：这些数据不会上传到任何地方。「输入」页最下面能看到占了多少、可以一键清掉

## 保存到本地的四种方式

手机上解压 ZIP 挺麻烦的，所以不止一种方式，工具会按你的设备把推荐的那个标成实心按钮：

| 方式 | 说明 | 什么时候用 |
|---|---|---|
| **分享 / 存到手机** | 调系统分享面板，直接存进「文件」或相册 | **手机首选**，不用解压。浏览器支持 Web Share 才会出现 |
| **存到文件夹** | 选一个文件夹，图片直接写进去 | **电脑首选**，也不用解压。Chrome / Edge 才有 |
| **逐张保存** | 一张张下载 | 哪都能用的兜底。手机上可能先问你「是否允许下载多个文件」，允许即可 |
| **打包 ZIP** | 一个文件装完 | 电脑上最省事，手机上要自己解压 |
| **只要清单 CSV** | 只下对照清单，不下图 | 想先看看都有哪些图的时候 |

存到手机「文件」里会保留 `001`、`002` 的编号文件名；存到相册会被系统重命名，
不过之后配对靠顺序和图像指纹一样能对上。

## 还没有图床？

「搭建图床」这一页会带你把图床从零搭起来，四种方式各有取舍：

| 方式 | 要花什么 | 适合 |
|---|---|---|
| **GitHub + jsDelivr** | 免费，不用绑卡 | 想长期存、不怕图被人看到。仓库是你自己的，服务方跑路了图还在。缺点是 jsDelivr 在国内常被 DNS 污染 |
| **ImgBB** | 免费，注册就用 | 只想赶紧搬完不折腾。缺点是没有标准删除接口 |
| **S.EE（原 SM.MS）** | 新用户要买套餐 | 老用户续用。注意 SM.MS 已整体迁到 s.ee，密码没一起迁移，要重设 |
| **Cloudflare R2** | 要绑卡（免费额度内不扣费） | 最耐用。10GB 免费空间、出口流量全免费 |

每一步都写清楚了去哪个页面点什么，需要复制的内容有复制按钮，填完点「测试连接」就知道配置对不对，
通过之后配置会自动填进「转存到图床」。

选 R2 的话要部署一个 Worker —— 就是下面说的那个中转 Worker，**一份代码同时干两件事**：
给 R2 收图，以及中转抓取旧图床里跨域/防盗链的图。不用部署两个。

## 怎么用

### 方式一：直接开网页

把这个仓库开 GitHub Pages（Settings → Pages → 选 main 分支根目录），
然后访问 `https://你的用户名.github.io/仓库名/` 就能用了。

### 方式二：本地打开

把仓库下载下来，双击 `index.html` 即可。没有任何构建步骤，不依赖 npm、不加载任何 CDN。

> 本地直接双击打开时，浏览器会把页面当成「无来源」，抓外部图片更容易被跨域挡住。
> 想稳一点就在仓库目录里起个静态服务器：`npx serve` 或 `python3 -m http.server`。

## 换图床的两种路子

### A. 让工具直接帮你传

「图片」页 → 转存到图床 → 选图床、填 token → 开始上传。
这种情况下新旧对应关系是**确定的**，不用猜，直接去「导出」拿新代码。

### B. 你自己去别的图床手动传

有些人就是想换个图床自己传，不想搭任何东西。那就：

1. 在「图片」页用上面任一种方式把图存下来，文件已经按 `001`、`002`… 编好号
2. **按这个顺序**传到你选的新图床，把拿到的新链接复制下来
3. 回到「对照」页，把新链接一行一个粘进去，点**导入并自动匹配**

工具会用四层线索去猜哪张对哪张，从硬到软：

| 线索 | 说明 |
|---|---|
| **图像指纹** | 算 dHash 比对图像内容，长得一样就配上。需要浏览器能读到新图的像素，图床不给跨域时读不到 —— 走 Worker 中转可以解决，读不到的会标成未验证 |
| **文件名** | 新链接里保留了原文件名或序号就能对上 |
| **图片尺寸** | 新旧图宽高一致是很强的提示，而且**不受跨域限制**，基本都拿得到 |
| **上传顺序** | 最弱的兜底，图床批量上传经常会乱序，所以只标「低」可信度 |

每一对都会标 **高 / 中 / 低**，不会当成百分百确定。猜错的地方你可以手动改：

- **点选交换**：点某一行右边的格子选中，再点另一行的格子 → 两张互换
- **分配**：点一张「待分配」的新图，再点某一行的格子 → 分过去
- **上移 / 下移**：整体错位一格时最好用
- **单独覆盖**：每行下面都能直接粘一个链接
- **电脑上还可以拖拽**：把待分配的图拖到某一行

旧图已经失效、左边看不到的，可以点「上传原图对照」，用你手里的原图当左边的参照。

### 关于 Worker 中转

浏览器直接抓别人服务器上的图，遇到**跨域限制**或**防盗链**会失败 —— 这是浏览器的硬限制，
纯前端绕不过去。所以工具支持可选的 Cloudflare Worker 中转：**不填就走浏览器直抓，填了就走中转**。

Worker 在服务器端取图，不带网页来源，这两个问题都能绕开。
代码和三分钟部署步骤在 [`worker/README.md`](worker/README.md)，免费额度足够用。

用 Cloudflare R2 存图的话必须配它（R2 不支持浏览器直传）。
S.EE 和自定义接口如果报跨域错误，也可以勾上「通过 Worker 中转上传」。

## 各图床要填什么

| 图床 | 需要的东西 | 在哪拿 |
|---|---|---|
| **GitHub + jsDelivr** | 用户名、仓库名、Token | GitHub → Settings → Developer settings → Personal access tokens，勾 `repo`（细粒度 token 给 Contents 读写即可）。仓库必须是 public，jsDelivr 才读得到 |
| **ImgBB** | API Key | 登录 imgbb.com 后打开 api.imgbb.com 点 Get API key |
| **S.EE（原 SM.MS）** | API Token | 登录 s.ee → 控制台 API Token 页面。单张 5MB、每分钟 20 张，工具会自动放慢速度。接口域名可以在 s.ee / sm.ms 之间切 |
| **Cloudflare R2** | 部署好的 Worker | 见 `worker/README.md` |
| **自定义接口** | 接口地址、字段名、Authorization、链接字段路径 | 按你的图床文档填。兰空图床 V2 举例：接口 `https://域名/api/v1/upload`，字段名 `file`，链接字段 `data.links.url` |

勾了「在本机记住这些配置」，token 会存在浏览器的 localStorage 里，方便下次用；
公用电脑别勾，随时可以点「清除已保存的配置」。

## 目录结构

```
index.html          页面
css/style.css       样式（跟随系统深色模式）
js/util.js          通用工具
js/extract.js       链接提取 + 按字符区间原样替换
js/zip.js           ZIP 打包（自己实现，不引任何库）
js/imaging.js       图片探活 / 取二进制 / dHash 指纹
js/hosts.js         各图床适配器
js/match.js         新旧图自动配对与可信度评分
js/setup.js         搭建图床向导（各家的步骤、直达链接、连接测试）
js/store.js         本机缓存（IndexedDB 存进度和图片，用不了就退回 localStorage）
js/app.js           主流程
worker/             Cloudflare Worker 中转（可选）
```
